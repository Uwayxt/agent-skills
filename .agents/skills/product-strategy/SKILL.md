# Product Strategy

**Strategy is saying no to good ideas so you can say yes to the right ones. A feature list without prioritization is a wish list.**

### 1. Articulate positioning
Write one sentence: for [target user], [product] is the [category] that [key differentiator], unlike [alternative].

### 2. Harvest the feature list
Collect every feature mentioned, implied, or assumed. No filtering yet.

### 3. Apply a prioritization framework
Score every feature. Use RICE (Reach × Impact × Confidence ÷ Effort) by default. Offer MoSCoW if the user prefers simpler buckets.

### 4. Draw the line
Where does the cut fall? Everything above ships first. Everything below is "later" with a reason.

### 5. Write the strategy one-pager
Compile the positioning statement, top priorities, and what is explicitly deferred and why.

### Completion Criteria
Done when every harvested feature has a score and a disposition (build now / defer / kill).

### Output Format
Strategy One-Pager with positioning statement, prioritized feature table (scored), and deferred list.
